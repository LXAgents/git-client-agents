# 1.16.1 — 2026-11-02

## Changed

- **Bigger message boxes.** On the Chat page, the Agent work and Team chat boxes now span their pane, start four lines tall and grow with the text up to about 13 lines, then scroll. The hint and a **Send** button sit under the box, so the narrow Team chat pane keeps its width for text.
- The three panes are taller (82% of the window height, at least 36rem).

## Requires

- git-server-agents 1.19.1 or later for the agent to create, close and reopen issues and pull requests from repository rooms (no dashboard change needed for that).
